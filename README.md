# Lavage Pro - Gabon

Application web PWA (Progressive Web App) de gestion et de mise en relation pour les centres de lavage de véhicules à Port-Gentil et Libreville.

## Fonctionnalités :
- Gestion opérationnelle hors-ligne pour les gérants (suivi de la file, caisse, équipe).
- Grille tarifaire personnalisable à l'inscription.
- Module Marketplace avec détection automatisée des clients issus de la plateforme (-5%).
- Essai gratuit de 30 jours avec verrouillage automatique à échéance.
- Double interface sécurisée Gérant / Patron.
